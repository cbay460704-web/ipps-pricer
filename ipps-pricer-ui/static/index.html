Batch pricing from a spreadsheet

One claim per row, seven columns: label, ccn, drg, discharge date, charges, los, covered days. Hospitals are matched by CCN to the saved profiles on the Hospitals tab; a CCN with no profile uses the hospital selected on the Price a claim tab. Any extra pricer field can be added as its own column (for example diagnosisCodes or provider.bedSize). Files are priced on the server with parallel workers, so tens of thousands of rows take well under a minute; results are written to a file you download when it finishes.

Hospital profiles

Enter each hospital's Provider Specific File values once. Profiles are saved to profiles.json next to the app and matched by CCN. Only the Essentials group normally needs filling in; everything else defaults to the values a standard hospital has.

Request JSON

The exact request that will be sent to the pricer, with defaults filled in. Edit or paste, then “Price JSON”; “Apply to form” copies values back.
